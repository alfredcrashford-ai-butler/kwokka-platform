Hey everyone!
We’ve just dropped an update — **v0.22.0**. Here’s what’s new:

## 🏍️ New Game Engine

![New Game Engine](/public/pages/news/releases/0.22.0/0.22.0_1.webp)

We’ve switched to a new game engine to boost performance and ensure the smoothest possible
experience. This is a huge milestone for us. While there hasn’t been much new content in this
update, the engine switch unlocks a wide range of opportunities — especially in terms of visual
improvements and special effects.

## 💅 Improved UX

The new engine enables smoother user interactions. Here are some of the most impactful changes:

- One-click card play;
- Enhanced card interactions;
- Enhanced spell interactions.

## 🐞Bugfixes

We managed to locate and fix few small bugs that were affecting the game process.
